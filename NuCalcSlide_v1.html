基準：—
エネルギー 炭水化物 タンパク質 脂質 塩分 食器/盛り 行操作
・メニュー：N + HEX14（56bit：|E10|C10|P10|F10|S10|T6|）
・Dタグ：D + HEX2（上位5bit=食器コード、下位3bit=大きさ/盛りコード）
・食器コード: 0=変更なし, 1=平皿, 2=小皿, 3=深皿, 4=茶碗, 5=丼, 6=鉢, 7=タンブラー, 8=ボトル
・盛りコード: 1=小(0.6), 2=普通(1.0), 3=大(1.6), 4=特盛(2.0)
・最終値 = 基本栄養値 × 食器倍率 × 盛り倍率
・食器コード0は「食器は変更せず、盛りだけ変更」です
・Dタグは「最後にNを入れた行」を優先して再計算します
・属性：A + HEX2（性別/年齢/活動を自動セット）

基準：—
    Dタグ一覧（食器 / 盛り）
    Dタグ = 上位5bit: 食器コード / 下位3bit: 盛りコード

    食器コード

    • 0: 変更なし（現在の食器を維持）
    • 1: 平皿（×1.0）
    • 2: 小皿（×0.4）
    • 3: 深皿（×1.2）
    • 4: 茶碗（×1.0）
    • 5: 丼（×1.2）
    • 6: 鉢（×0.6）
    • 7: タンブラー（×0.7）
    • 8: ボトル（×1.5）

    盛りコード

    • 1: 小（×0.6）
    • 2: 普通（×1.0）
    • 3: 大（×1.6）
    • 4: 特盛（×2.0）

    例

    • D0A → 平皿 / 普通
    • D0B → 平皿 / 大
    • D13 → 小皿 / 大
    • D1C → 深皿 / 特盛
    • D04 → 食器変更なし / 特盛

入力欄をタップしてQRコードを読み取ってください。
Nタグは平文、Aタグ・DタグはHEX形式です。

基準：—
エネルギー 炭水化物 タンパク質 脂質 塩分 食器/盛り 行操作
・入力欄タップでQR読み取りモーダルを開きます
・Nタグ（平文フル）: N E/650 C/85.0 P/22.5 F/18.0 S/2.3
・Nタグ（単項目更新）: N S/1.8 / N E/540
・Aタグ: A + HEX2
・Dタグ: D + HEX2
・単項目Nタグは「最後にNタグを入力した行」を更新します
・Dタグは「現在行 → 最後にNタグを入力した行」の順で適用します

    • 5: 丼（×1.2）
    • 6: 鉢（×0.6）
    • 7: タンブラー（×0.7）
    • 8: ボトル（×1.5）

    盛りコード

    • 1: 小（×0.6）
    • 2: 普通（×1.0）
    • 3: 大（×1.6）
    • 4: 特盛（×2.0）
